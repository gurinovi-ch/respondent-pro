# AGENTS.md

## Визуальные проверки — НЕ проводить

Не открывать скриншоты/изображения в Review-панели и не делать визуальные
проверки за пользователя (предпочтение пользователя, 2026-09-29).

Пользователь сам смотрит скриншоты и подтверждает визуальное поведение.

Верификация со стороны агента — только инструментальная:
- юнит-тесты (`testDebugUnitTest`)
- `dumpsys` / `adb shell` (видимость окон, фокус, lock task)
- логи (`logcat` c `Log.i`)
- grep/анализ исходников
