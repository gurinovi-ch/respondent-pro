## Kiosk mode for RESPONDENT.PRO (spec §12)

Реализация киоск-режима для планшета-интерактива: 10 задач, каждая прошла отдельное code review; финальное ревью всей ветки — READY (must-fix: 0).

### Что входит
- **Device Owner + Lock Task** (T1–T3): политики блокировки, whitelisting, максимальный локдаун
- **HOME-лаунчер + автозапуск** (T4): приложение как основной лаунчер, старт после перезагрузки
- **Crash recovery + watchdog** (T5): автоперезапуск после краша/убийства процесса
- **Экскурсия в настройки Android** (T6): PIN-protected ссылка + плавающая кнопка возврата
- **QR-провижининг** (T2, T9): настройка нового планшета без ПК, шаринг через FileProvider
- **GitHub Releases APK** (T7): ссылка для скачивания в QR/инструкции
- **Карточка «ИНФОКИОСК»** (T8): статус Device Owner ✅/⚠️ + копируемые adb-команды
- **Финальная приёмка** (T10): чек-лист spec §12 — 10/10 PASS

### Верификация
- Юнит-тесты: **16/16** (KioskPolicy, ProvisioningQr + encode smoke, WatchdogScheduler, KioskStrings)
- Приёмка на устройстве (Lenovo TB-X606X, Android 10): **10/10 PASS**
- P1 (рестарт после перезагрузки), P2 (восстановление ≤60с), P5 (краш-рестарт) — PASS
- QR декодируется byte-for-byte (R12)
- Без политиков, блокирующих отладку (USB debugging остаётся доступным)

### Отклонения/заметки
- Задержка firmware-аларма: краш-рестарт фактически ~5–7с вместо <2с из спеки (принято, R10)
- `dpm remove-device-owner` отсутствует на Android 10 прошивке — приёмка пункта 7 по T8-доказательствам (R13)
- APK-URL — pinned tag `v1.0-test`, не `/latest/` (принятый компромисс T7)
- 40+ отложенных миноров зафиксированы в SDD-ledger; top-4 рекомендованы в follow-up: crash-loop backoff, ON_RESUME refresh статуса DO, сужение FileProvider path + очистка QR PNG, маскировка пароля Wi-Fi
